# Calistenia em Casa — Marcus do Vale

Treino em casa, sem aparelhos. Só o peso do corpo — e a corda quando chegar em casa ou no fim de semana.

## O que tem no app

- **`index.html`** — o app inteiro num arquivo só. Abre no celular e no PC, funciona offline depois de aberto a primeira vez. Não precisa instalar nada.
- **`videos/`** — 24 vídeos curtos (10 s cada) com a execução correta, embutidos no app, todos no próprio site. Todos os 21 exercícios têm Forma 1 e Forma 2 com vídeo — nenhum exercício ficou sem vídeo e não há link externo.
- **Cronômetro:** aba Cronômetro com tempo de exercício + descanso em voltas (ex.: 30 s de exercício, 60 s de descanso, 4 voltas), com apito na troca, e botões rápidos de 30/45/60 s de exercício e 60/90 s de descanso.
- **Hoje:** o treino do dia, pela semana.
- **Treinos:** 5 treinos sem aparelhos (A a E), com séries, repetições, como fazer, erro comum e versão mais fácil / mais difícil.
- **Corda:** 3 treinos guiados com timer automático — 10 min (leve, quando chegar em casa), 15 min (ritmo) e 20 min (fim de semana).
- **Exercícios:** biblioteca com busca e filtro por músculo.
- **Progresso:** treinos feitos, minutos, meta de 3 treinos por semana. Tudo salvo no próprio celular (navegador), nada vai para servidor nenhum.

## A semana

| Dia | Treino | Tempo |
|---|---|---|
| Segunda | A — Empurrar + core | ~20 min |
| Terça | B — Pernas + glúteo | ~20 min |
| Quarta | Descanso ou corda leve 10 min | 10 min |
| Quinta | C — Puxar na mesa + costas | ~20 min |
| Sexta | D — Corpo inteiro (circuito) | ~25 min |
| Sábado | Corda 20 min + circuito curto | 20 min |
| Domingo | E — Mobilidade e alongamento | 10 min |

Nível: Iniciante ou Intermediário, troca no topo do app. O nível muda as repetições e os tempos.

## Regra de evolução

Quando fizer todas as séries no topo da faixa (ex.: 3x12 flexão) com boa forma em 2 treinos seguidos, sobe um degrau: +2 repetições por série, ou passa para a versão mais difícil. Não sobe repetição e dificuldade ao mesmo tempo.

## Corda

- Ajuste: pisa no meio da corda com um pé, as manoplas têm que chegar na altura do peito / axila.
- Técnica: cotovelo junto do corpo, giro no pulso, pulo baixo na ponta do pé, joelho mole.
- Sem corda ainda? Faz o mesmo treino com pulo imaginário (gira o pulso) ou polichinelo.

## Mesa de vidro

Mesa de vidro NÃO serve para remada na mesa — pode quebrar e machucar. Usa a Forma 2 da remada: remada com mochila, com uma mão e um joelho apoiados numa cadeira firme. A mochila vai com livros ou garrafas dentro.

## Publicar no GitHub (2 min)

O repositório ainda não foi criado porque o GitHub não está logado neste servidor. Faça assim:

1. No GitHub, crie o repositório **`calistenia-em-casa`** (público ou privado, como preferir) na conta `MarcusdoVale`.
2. No PC, dentro desta pasta, rode:
   ```bash
   git init
   git add .
   git commit -m "Calistenia em Casa: treinos sem aparelhos + corda"
   git branch -M main
   git remote add origin https://github.com/MarcusdoVale/calistenia-em-casa.git
   git push -u origin main
   ```
3. Para o site ficar no ar: no GitHub, Settings → Pages → Source: Deploy from a branch → Branch: main → Save. O endereço fica `https://marcusdovale.github.io/calistenia-em-casa/`.
4. No celular, abre esse endereço e usa "Adicionar à tela inicial" — vira um app.

## Segurança

Conteúdo educativo, não substitui orientação de profissional de educação física ou médico. Aquece 2 min antes. Dor aguda, pontada ou tontura = para na hora. Na remada na mesa, usa mesa pesada e firme, sem rodinha — testa com o peso antes.
